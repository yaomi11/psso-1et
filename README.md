# PSSO-1ET (Pracownia Serwerowych Systemów Operacyjnych)

Repozytorium zawiera kompletną dokumentację, instrukcje oraz materiały z zajęć laboratoryjnych (tematy T02–T12) z zakresu planowania instalacji, wirtualizacji, konfiguracji systemów **Windows Server 2025** i **Windows 11** oraz zarządzania usługami Active Directory (AD DS).

## Spis tematów laboratoryjnych

* **T02:** Planowanie instalacji systemów
* **T03:** Konfiguracja maszyn wirtualnych w VirtualBox
* **T04:** Instalacja i konfiguracja Windows Server 2025
* **T05:** Instalacja i wstępna konfiguracja Windows 11
* **T06:** Wprowadzenie do usług Active Directory
* **T07:** Konfiguracja kontrolera domeny
* **T08:** Zarządzanie kontami użytkowników (GUI)
* **T09:** Zarządzanie kontami w środowisku PowerShell
* **T10:** Jednostki organizacyjne (OU) i grupy
* **T11:** Narzędzia konsolowe i polecenia typu `dsadd`, `dsquery`
* **T12:** Prawa użytkowników i dziedziczenie uprawnień w AD

## Struktura katalogu każdego ćwiczenia
Każdy folder w katalogu `cwiczenia/` zawiera:
* `instrukcja.md` – Szczegółowy opis krok po kroku danego zagadnienia.
* `screeny/` – Zrzuty ekranu dokumentujące poszczególne etapy konfiguracji.

## Wymagania wstępne i przydatne linki
* Oprogramowanie do wirtualizacji: [Oracle VirtualBox](https://www.virtualBox.org)
* Obrazy instalacyjne systemów (Windows Server 2025 oraz Windows 11): [winiso.pl](https://winiso.pl)
